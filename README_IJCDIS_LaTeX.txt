IJCDIS LaTeX manuscript template — pre-launch

1. Edit IJCDIS_LaTeX_Template.tex.
2. Keep figures as separate high-resolution files.
3. For formal submission (once opened), submit the editable .tex source, all figures/tables/bibliography files, and a compiled PDF.
4. Do not include author-identifying information in the anonymized review manuscript when double-blind review is used.
5. Follow the current Guide for Authors on the journal website; website instructions override this draft template if they differ.

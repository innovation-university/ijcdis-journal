# موقع مجلة ICSIS — حزمة GitHub Pages المجانية

## ما الموجود في الحزمة؟
موقع ثابت متعدد الصفحات يعمل دون قاعدة بيانات أو اشتراك مدفوع، ويشمل:
- الصفحة الرئيسية ونطاق المجلة.
- هيئة التحرير بحالة «قيد التشكيل» دون أسماء وهمية.
- دليل المؤلفين وسياسة التحكيم وأخلاقيات النشر.
- صفحة الأعداد بحالة «العدد الافتتاحي قيد الإعداد».
- صفحة تقديم غير مفعلة حتى تجهيز المسار الرسمي.
- صفحة اتصال وحدود استخدام البريد الحالي.

## النشر المجاني على GitHub Pages
1. أنشئ حسابًا مؤسسيًا للمجلة على GitHub، وليس حسابًا شخصيًا لأحد أعضاء الفريق.
2. أنشئ مستودعًا عامًا باسم مثل `icsis-journal`.
3. ارفع كل محتويات هذا المجلد إلى الجذر، بما فيها `.nojekyll`.
4. من **Settings → Pages** اختر **Deploy from a branch**، ثم فرع `main` والمجلد `/root`.
5. سيظهر رابط مؤقت مثل: `https://organization.github.io/icsis-journal/`.
6. الأفضل لاحقًا ربط نطاق فرعي رسمي مثل `journal.iu.edu.eg` بعد موافقة تقنية المعلومات.

## تعديلات إلزامية قبل الإطلاق الرسمي
- اعتماد الاسم الإنجليزي النهائي نفسه في كل الخطابات والموقع والـISSN.
- استبدال بريد الاتصال ببريد مخصص للمجلة.
- إدراج العنوان البريدي الكامل للناشر.
- إضافة أسماء هيئة التحرير بعد التحقق والموافقة المكتوبة فقط.
- تفعيل التقديم عبر OJS أو منصة بنك المعرفة أو نظام مؤسسي موثق.
- إضافة أرقام ISSN وDOI والفهرسة فقط بعد صدورها والتحقق منها.
- حذف `noindex,nofollow` من صفحات HTML وتعديل `robots.txt` بعد الاعتماد الرسمي فقط.

## حدود GitHub Pages
GitHub Pages يستضيف ملفات HTML/CSS/JS، لكنه **ليس نظام إدارة مجلة**: لا يوفر تحكيمًا مزدوج التعمية، أدوار مستخدمين، تتبع قرارات، حفظًا مؤسسيًا، ولا إصدار DOI. لذلك يستخدم كواجهة أولية، بينما يفضل OJS على خادم الجامعة أو منصة بنك المعرفة كسير عمل دائم.

## تعديل المحتوى
الصفحات ملفات HTML عادية. ابحث عن النص المطلوب وعدله مباشرة. التصميم في `assets/styles.css`، والقائمة المتحركة في `assets/script.js`.

## تنبيه نزاهة
لا تنشر مقالات أو أعدادًا تجريبية على أنها منشورة، ولا تستخدم بيانات أو نتائج أو أسماء مؤلفين أو محكمين غير حقيقية لإكمال عدد مطلوب.

# IJCDIS Online Submission Form — field specification

Recommended platform: Tally (journal-owned account).

## Page 1 — Manuscript
- Manuscript title (required)
- Article type (required)
- Abstract (required)
- Keywords (required)

## Page 2 — Corresponding author
- Full name (required)
- Institutional email (required)
- Affiliation (required)
- ORCID URL
- All authors and affiliations in publication order (required)

## Page 3 — Files
- Source format: Microsoft Word (.docx) / LaTeX source package (.zip)
- Manuscript source file (required)
- Review PDF (required)
- Cover letter (required)
- Supplementary files (optional)

## Page 4 — Declarations
- Funding statement
- Conflict of interest statement
- Data and code availability
- Ethics / consent statement, if applicable
- Generative AI disclosure, if applicable
- Originality / exclusive submission / author approval confirmation (required)
